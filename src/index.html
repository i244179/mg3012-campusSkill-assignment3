Assignment 3 · Truffle & Ganache

Your learning milestones, deployed locally with Truffle.

This is the CampusSkill contract from Assignment 2, compiled and migrated with Truffle onto a local Ganache blockchain. The page reads the ABI and contract address straight from Truffle's build artifact and sends real transactions from Ganache's test accounts.

How to use this dashboard

  1. Start Ganache and run truffle migrate
  2. Pick a Ganache account and publish a milestone
  3. Mark it as completed from the same account
